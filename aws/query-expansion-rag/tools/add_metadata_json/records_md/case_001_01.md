|**状況（客観的）**|母子健康手帳の記録では発育は標準範囲内。子どもは来所時も活発に動いており、体重・身長と<br>もに正常域にある。母親は化粧気がなく、目の下のクマが目立ち、来所時から疲弊した様子が見<br>て取れた。夫は仕事が多忙で週3日は出張があり不在、実家は新潟県で遠方のため、日常的に育<br>児の相談ができる人間が周囲にいない環境であると確認した。近隣に顔見知りもいないとのこ<br>と。||||
|**状況（主観的）**|「毎日子どもと二人きりで、誰とも話せない。夫は出張が多くて週に3日は帰れない。実家に電<br>話しても心配かけたくなくて、本当のことを言えない」と訴えた。笑顔はほとんど見られず、自<br>信なさげな様子。育児書やネット情報に振り回されている印象が強い。「自分が母親として失格<br>なのではないか」という言葉も聞かれ、自己評価の低下が示唆される。子育て支援センターの存<br>在は知っているが「行けていない」とのこと。||||
|**分析・判断**|子どもの発育に医学的問題はなく、母親の過度な心配が主訴の中心と考えられる。ただし、社会<br>的孤立・慢性的睡眠不足・サポートの不在が重なっており、育児負担が相当蓄積している状態。<br>現時点では大きなリスクは見当たらないが、孤立環境が継続すれば精神的消耗が進む可能性があ<br>り、継続的なフォローが必要と判断する。||||
|**対応**|子どもの発育が正常範囲であることを母子手帳の記録を示しながら丁寧に説明し、安心を促し<br>た。子育て支援センター・地域の育児サークルの情報提供を行い、利用を勧めた。育児相談窓口<br>（電話・来所）の案内を行い、いつでも相談できることを伝えた。次回の1歳6ヶ月健診（8月予<br>定）での状況確認を約束した。||||
