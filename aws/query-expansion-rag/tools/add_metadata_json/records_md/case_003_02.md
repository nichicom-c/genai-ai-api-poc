|**状況（主観的）**|「部下の仕事のミスをカバーしながら、上からはプレッシャーをかけられて、間に挟まれている<br>感じが続いている。家に帰っても仕事のことが頭から離れない。妻には『顔が変わった』と言わ<br>れたが、大げさだと思う」と述べた。「酒は飲みすぎとは思うけど、飲まないと何か落ち着かな<br>い。ないと不安というか」と付け加えた。笑顔は前回より少なく、話す声に覇気がなかった。||||
|**分析・判断**|飲酒量・頻度の急激な増加（入眠目的）、体重減少、食欲不振、睡眠時間の短縮が重なってお<br>り、慢性的なストレス過負荷状態にある。「飲まないと不安」という発言はアルコール依存への<br>移行リスクを示唆する。過重労働との複合で、精神的健康が悪化しつつあると判断。産業医への<br>連携および精神科・心療内科受診の検討を勧める時期と見る。||||
|**対応**|飲酒量の増加とその背景にあるストレスについて丁寧に確認した。アルコールは一時的な入眠効<br>果があるが睡眠の質を下げること、依存リスクがあることを説明した。産業医への相談を勧め、<br>心療内科・精神科受診も選択肢として提示した。「弱さではなく、体のSOSサイン」と伝え、受<br>診への抵抗感の軽減を図った。次回を6週間後に設定した。||||
