|**状況（客観的）**|電話口での母親の声は著しい疲労感が漂っており、話す速度が遅く、言葉が途切れがちであっ<br>た。前回（6月8日）来所時に案内した子育て支援センターへは一度も行けていないとのこと。一<br>時保育の申し込みも「手続きが面倒で手が付けられなかった」と述べていた。夫は当日も出張中<br>であり、自宅に相談者はいない状況が継続している。||||
|**状況（主観的）**|「もう限界に近い気がする。子どもが夜中に泣き続けているとき、なんで泣き止まないのかと腹<br>が立ってくる。…叩きたくなることがある、と思う自分がこわい」と小声で打ち明けた。その後<br>すぐに「でも絶対にしない」と付け加えたが、声は震えていた。「こんなことを言ってしまっ<br>て、子どもを取られてしまうか心配」とも述べており、支援への不信・恐怖が伺える。||||
|**分析・判断**|育児疲労・睡眠不足が限界に近づいている。「叩きたくなる」という発言は育児リスクの高まり<br>を示すサインとして注意が必要。本人は自制できていると述べているが、現状が継続すれば不適<br>切な関わりが生じる可能性が高まる。早急なレスパイト支援の導入と、本人が安心して相談でき<br>る関係の構築を優先する。||||
|**対応**|気持ちを十分に傾聴し、「叩きたいと感じてしまうことは、追い詰められているサイン。話して<br>くれたことが大事」と伝え、受容的に関わった。一時保育および市の子育て短期支援事業<br>（ショートステイ）の概要を説明し、申し込み手続きのサポートを提案した。夫への相談も改め<br>て促した。来週中に来所での面談を設定した。||||
