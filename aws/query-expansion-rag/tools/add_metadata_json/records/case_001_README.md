## 問題シナリオの概要

孤立した環境で育児を続ける母親が、睡眠不足・精神的疲弊の蓄積により「叩きたくなる」「揺さぶってしまった」と告白するまでの経緯を描く。  
各記録は単独でも読めるが、5件を通して読むことで育児虐待リスクが段階的に顕在化する様子が浮かび上がる構成になっている。  
最終的には父親の協力・一時保育の導入・要保護対策協議への連携によって支援体制が整う方向に動く。

## RAGシステムでの利用想定

このデータは、育児支援・要保護児童対策に関する問い合わせ（例：「育児疲れを相談してきた母親にどう対応すべきか」「揺さぶりの告白があった場合の手順は」）に対する**ケースベースの回答支援**テストに適している。  
5件が時系列で連続しているため、「この対象者の過去の経緯は？」のような**複数文書横断の文脈理解**を評価するクエリにも有効である。
