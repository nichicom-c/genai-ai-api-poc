別記様式１　（第3回）
相談日時 令和5年8月21日（月）　14:00 ～ 15:10
相談者 相談者（本人） 対象者 藤本 さくら（34歳・女性）
相談方法 来所
目的 前回（6月2日）来所のフォローアップ。夏休み期間中の生活状況の確認および精神的健康の把握。
主　訴 「夏休み中は娘がずっと家にいるので、夫がいつ怒鳴るか気が気でない。先週も夕食のことで大きな声を出されて、娘が泣き出してしまった。娘に申し訳なくて」
状況（客観的） 来所時、表情は険しく、話す間に何度も周囲を確認するような動作が見られた。身体的な外傷は今回確認されなかった。夏休みは娘と二人で過ごす時間が長く、夫の帰宅時間を常に気にしているとのこと。パートは夏季休業中で収入が一時的に減っており、夫から「お前が稼がないから足りない」と言われることが増えたと述べた。
状況（主観的） 「夫が怒鳴るのは私のせいだと分かっているんです。でも、娘の前でされると…娘がびくびくするようになってしまって、それが一番つらい」と涙をこらえながら述べた。「自分への暴力ではない」と繰り返し強調したが、「物を投げられることはある」と小声で付け加えた。「逃げたいと思うことはあるけど、行く場所もないし、夫に迷惑をかけるのも…」と言いかけて話を止めた。
分析・判断 怒鳴り・物を投げる行為はDVの精神的・身体的暴力の範疇に入る。娘への影響（びくびくする様子）も確認された。本人はDVと認識できていないか、認識していても否定している可能性がある。「逃げたい」という発言は安全確保への意思の萌芽と見る。配偶者暴力相談支援センターとの連携を上司と検討する段階と判断する。
対応 「あなたのせいではない」と明確に伝えた。DVとは何か（身体的・精神的・経済的暴力）についてパンフレットを使いながら丁寧に説明した。「今すぐ決断しなくていい。でも、いつでも相談できる場所がある」と伝え、配偶者暴力相談支援センターの連絡先を案内した。緊急時の対応（安全な場所への避難、警察・支援センターへの連絡）についても簡単に説明した。
今後の計画 約6週間後（10月上旬）を目安に面談を設定。緊急の場合は随時対応。配偶者暴力相談支援センターへの情報共有を上司と協議する。 【支援時期】
