相談方法 来所
目的 前回（4月11日）来所のフォローアップ。身体症状の経過確認および生活状況の把握。
主　訴 「頭痛は少し落ち着いてきた。でも、また眠れない日が続いていて。あと、先週ちょっと棚の角に顔をぶつけてしまって…」（右頬に内出血あり）
状況（客観的） 来所時、右頬骨付近に直径約4cmの内出血が確認された。本人は「棚の角にぶつけた」と説明したが、打撲の形状・位置は棚角との接触で生じやすいものと断定できない。表情は前回より硬く、声が小さかった。化粧でやや隠している様子も見受けられた。体重はさらに1kg減少（本人申告）。前回紹介した内科への受診は「行けていない」とのこと。
状況（主観的） 打撲の経緯を穏やかに尋ねると、一瞬間があってから「本当にぶつけただけなんですけど」と繰り返した。その後しばらく沈黙し、「夫が最近、家のことをもっとちゃんとしろって強く言うことがあって。私が何かするたびにダメ出しされる感じで、疲れてきた」と述べた。「でも、夫なりに仕事が大変なんだと思う」と夫をかばう言葉もあった。娘については「学校には楽しく行っている」と述べた。
分析・判断 右頬の内出血と説明内容のずれ、前回からの体重減少継続、夫の言動に関する発言の増加が気になる。DVの可能性を念頭に置きつつ、本人が安心して話せる関係を引き続き構築する必要がある。現時点では断定せず、慎重に傾聴を続ける。内部での情報共有を行う。
対応 打撲について「痛みがあれば病院へ」と伝えつつ、責める印象にならないよう配慮した。「いつでも話を聞きます」と伝え、相談窓口の案内カードを渡した。次回は2ヶ月後を目安としつつ、「何かあればすぐ連絡してほしい」と伝えた。面談後、担当上司に状況を報告し情報共有を行った。
