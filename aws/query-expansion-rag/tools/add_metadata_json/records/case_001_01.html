別記様式１　（第1回）
相談日時 令和5年6月8日（木）　10:30 ～ 11:00
相談者 相談者（本人） 対象者 中村 明日香（28歳・女性）／長男 中村 颯太（1歳2ヶ月）
相談方法 来所
目的 1歳6ヶ月健診前のフォローアップ。子どもの発育・発達に関する母親の不安への対応および育児環境の確認。
主　訴 「子どもが思うように発達していないかもしれない。ネットで調べるたびに心配なことばかり出てきて、夜も眠れない日が続いている。夫には心配させたくなくて相談できていない」
状況（客観的） 母子健康手帳の記録では発育は標準範囲内。子どもは来所時も活発に動いており、体重・身長ともに正常域にある。母親は化粧気がなく、目の下のクマが目立ち、来所時から疲弊した様子が見て取れた。夫は仕事が多忙で週3日は出張があり不在、実家は新潟県で遠方のため、日常的に育児の相談ができる人間が周囲にいない環境であると確認した。近隣に顔見知りもいないとのこと。
状況（主観的） 「毎日子どもと二人きりで、誰とも話せない。夫は出張が多くて週に3日は帰れない。実家に電話しても心配かけたくなくて、本当のことを言えない」と訴えた。笑顔はほとんど見られず、自信なさげな様子。育児書やネット情報に振り回されている印象が強い。「自分が母親として失格なのではないか」という言葉も聞かれ、自己評価の低下が示唆される。子育て支援センターの存在は知っているが「行けていない」とのこと。
分析・判断 子どもの発育に医学的問題はなく、母親の過度な心配が主訴の中心と考えられる。ただし、社会的孤立・慢性的睡眠不足・サポートの不在が重なっており、育児負担が相当蓄積している状態。現時点では大きなリスクは見当たらないが、孤立環境が継続すれば精神的消耗が進む可能性があり、継続的なフォローが必要と判断する。
対応 子どもの発育が正常範囲であることを母子手帳の記録を示しながら丁寧に説明し、安心を促した。子育て支援センター・地域の育児サークルの情報提供を行い、利用を勧めた。育児相談窓口（電話・来所）の案内を行い、いつでも相談できることを伝えた。次回の1歳6ヶ月健診（8月予定）での状況確認を約束した。
今後の計画 1歳6ヶ月健診（8月）時に改めて状況を確認。支援センター利用状況および夫との連携状況を把握する。必要に応じて次回来所面談を設定する。 【支援時期】
