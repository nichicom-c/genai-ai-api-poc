## 問題シナリオの概要

部署異動に伴う役職ストレスが「肩こり・不眠」という身体症状から始まり、アルコールへの依存傾向・欠勤・家族関係の悪化を経て、希死念慮に近い体験の告白・休職へと進行する。  
各記録は「ちょっと疲れているだけ」という本人の認識と、徐々に深刻化する実態のずれを描いており、5件を通して読むとストレスが長期間過小評価されてきた経緯が浮かび上がる。  
最終的には休職・精神科治療・認知行動療法の開始と妻との関係修復を経て回復へ向かう。

このデータは、職場ストレス・メンタルヘルス管理に関する問い合わせ（例：「飲酒量が増えて眠れないと相談してきた人への対応は」「希死念慮が示唆された場合の保健師の対応手順は」）に対する**ケースベースの回答支援**テストに適している。
