別記様式１　（第2回）
相談日時 令和5年7月10日（月）　13:00 ～ 13:55
相談者 相談者（本人） 対象者 西田 誠（45歳・男性）
相談方法 来所
目的 前回（5月15日）来所のフォローアップ。睡眠・疲労・飲酒習慣の経過確認および職場ストレスの状況把握。
主　訴 「眠れなくて困っている。寝ようとしても頭が冴えてしまう。最近は寝る前に酒を飲まないと眠れなくなってきた。食欲もあまりない」
状況（客観的） 来所時、前回と比べて表情が疲れており、顔色もやや悪い。体重は前回比約2kg減少。残業時間は月60時間超に増加しているとのこと。飲酒習慣については「毎晩、缶ビール3〜4本は飲むようになった。飲まないと眠れない」と述べた（前回は週3〜4回・1〜2本）。睡眠時間は4〜5時間程度に減少。食欲不振が2週間以上続いているとの申告。
状況（主観的） 「部下の仕事のミスをカバーしながら、上からはプレッシャーをかけられて、間に挟まれている感じが続いている。家に帰っても仕事のことが頭から離れない。妻には『顔が変わった』と言われたが、大げさだと思う」と述べた。「酒は飲みすぎとは思うけど、飲まないと何か落ち着かない。ないと不安というか」と付け加えた。笑顔は前回より少なく、話す声に覇気がなかった。
分析・判断 飲酒量・頻度の急激な増加（入眠目的）、体重減少、食欲不振、睡眠時間の短縮が重なっており、慢性的なストレス過負荷状態にある。「飲まないと不安」という発言はアルコール依存への移行リスクを示唆する。過重労働との複合で、精神的健康が悪化しつつあると判断。産業医への連携および精神科・心療内科受診の検討を勧める時期と見る。
対応 飲酒量の増加とその背景にあるストレスについて丁寧に確認した。アルコールは一時的な入眠効果があるが睡眠の質を下げること、依存リスクがあることを説明した。産業医への相談を勧め、心療内科・精神科受診も選択肢として提示した。「弱さではなく、体のSOSサイン」と伝え、受診への抵抗感の軽減を図った。次回を6週間後に設定した。
今後の計画 9月上旬を目安に次回面談を設定。産業医・心療内科受診の有無を確認。飲酒量・睡眠・残業時間の変化を継続把握する。 【支援時期】
