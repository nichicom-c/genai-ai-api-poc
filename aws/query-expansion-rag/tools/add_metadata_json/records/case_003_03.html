別記様式１　（第3回）
相談日時 令和5年9月4日（月）　11:30 ～ 12:30
相談者 相談者（本人） 対象者 西田 誠（45歳・男性）
相談方法 来所
目的 前回（7月10日）来所のフォローアップ。産業医・医療機関受診の有無確認および精神的健康状態の把握。
主　訴 「先月、2回ほど朝起きられなくて会社を休んでしまった。上司には体調不良と伝えたが、正直に言えなかった。妻とも最近ぎくしゃくしている」
状況（客観的） 来所時、目の下にクマが目立ち、表情は硬い。体重はさらに1.5kg減少（初回比−3.5kg）。産業医への相談・心療内科受診はいずれも「行けていない」とのこと。欠勤は8月に2日間。飲酒量は「缶ビール4〜5本の日もある」と述べた。休日も仕事のメッセージが届くため完全に休めていないとのこと。妻とは「会話が減った、口をきくと口論になる」と述べた。
状況（主観的） 「朝、体が動かない日があって、自分でも驚いた。仮病じゃないのに、うまく説明できなかった。ただ、疲れているだけだと思いたかった」と述べた。「家でも気が張っていて、子どもに怒鳴ってしまうことがある。自分が嫌になる」と言葉を絞り出すように話した。「病院に行くほどじゃないと思っていたが、最近は自信がなくなってきた」とも述べた。終始うつむきがちで、以前の明るさは見られなかった。
分析・判断 欠勤・体重減少・飲酒量増加・家族関係の悪化・朝の起床困難が重なっており、うつ状態への移行が強く疑われる。本人は受診を先送りにしているが「自信がなくなってきた」という発言はこれまでと異なる自己認識を示しており、受診につながるタイミングと判断する。今回の面談で具体的な受診行動を支援する。
対応 「朝起きられない、疲れが取れないのは体からの警告」と伝え、うつ症状についてパンフレットを用いて平易に説明した。心療内科への受診を強く勧め、近隣の受診可能な医療機関リストを提供した。「予約の電話が難しければ、一緒に考える」と伝えた。産業医への相談についても次の出勤日に行動に移すよう具体的に促した。次回を2ヶ月後に設定した。
今後の計画 11月上旬を目安に次回面談を設定。心療内科受診・産業医相談の有無を確認。状況が急変した場合は随時対応。 【支援時期】
令和5年11月
