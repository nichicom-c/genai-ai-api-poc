別記様式１　（第2回）
相談日時 令和5年7月24日（月）　13:30 ～ 14:30
相談者 相談者（本人） 対象者 中村 明日香（28歳・女性）／長男 中村 颯太（1歳4ヶ月）
相談方法 電話（着信）
目的 育児疲れによる精神的消耗への対応。夜泣きによる睡眠障害の改善支援および心理的安定化を図る。
主　訴 「夜泣きが毎晩続いて全く眠れない。昨日は朝4時まで泣き止まなかった。何をしても泣き止まないとき、どうしたらいいのか分からなくなってくる」
状況（客観的） 電話口での母親の声は著しい疲労感が漂っており、話す速度が遅く、言葉が途切れがちであった。前回（6月8日）来所時に案内した子育て支援センターへは一度も行けていないとのこと。一時保育の申し込みも「手続きが面倒で手が付けられなかった」と述べていた。夫は当日も出張中であり、自宅に相談者はいない状況が継続している。
状況（主観的） 「もう限界に近い気がする。子どもが夜中に泣き続けているとき、なんで泣き止まないのかと腹が立ってくる。…叩きたくなることがある、と思う自分がこわい」と小声で打ち明けた。その後すぐに「でも絶対にしない」と付け加えたが、声は震えていた。「こんなことを言ってしまって、子どもを取られてしまうか心配」とも述べており、支援への不信・恐怖が伺える。
分析・判断 育児疲労・睡眠不足が限界に近づいている。「叩きたくなる」という発言は育児リスクの高まりを示すサインとして注意が必要。本人は自制できていると述べているが、現状が継続すれば不適切な関わりが生じる可能性が高まる。早急なレスパイト支援の導入と、本人が安心して相談できる関係の構築を優先する。
対応 気持ちを十分に傾聴し、「叩きたいと感じてしまうことは、追い詰められているサイン。話してくれたことが大事」と伝え、受容的に関わった。一時保育および市の子育て短期支援事業（ショートステイ）の概要を説明し、申し込み手続きのサポートを提案した。夫への相談も改めて促した。来週中に来所での面談を設定した。
今後の計画 7月31日（月）に来所面談を実施し、一時保育申請の支援を行う。夫との連絡・相談状況を確認する。内部での情報共有（担当上司への報告）を行う。 【支援時期】
