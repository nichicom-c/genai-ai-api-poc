別記様式１　（第5回）
相談日時 令和5年10月15日（日）　10:30 ～ 11:45
相談者 相談者（本人） 対象者 藤本 さくら（34歳・女性）／長女（7歳）
相談方法 来所（配偶者暴力相談支援センター担当者同席）
目的 緊急電話（10月7日）後の安全確認および今後の支援方針の確認。配偶者暴力相談支援センターとの連携による一時避難・生活再建の支援計画策定。
主　訴 「やっと相談できてよかったと思っている。怖かったけど、娘のためにも動かないといけないと思った。施設に入れるなら入りたい。娘の学校のことが一番心配で」
状況（客観的） 10月7日の緊急電話後、本人は娘を連れ夜間に近隣の交番へ避難し、警察の支援を経て翌8日に配偶者暴力相談支援センターへ移動した。頭部打撲・左前腕部の内出血は医療機関にて確認・記録済み。現在はセンターの一時保護施設に滞在中。娘は落ち着いており施設スタッフとも話せている。本人の表情は疲弊しているが、来所時の視線に力があり、前回までとは異なる印象を受けた。
状況（主観的） 「逃げて初めて、ずっと怖かったんだと気づいた。家の中でいつも緊張していた。今は少し息ができる感じがする」と述べた。娘については「施設でご飯を食べながら笑っていて、久しぶりに見た顔だった」と涙をこらえながら話した。今後の生活については「お金がなくて不安。仕事を続けられるか、住む場所はどうなるか」と心配を示したが、「でも、戻るつもりはない」と明言した。
分析・判断 本人が避難を決断し、安全な環境に移れたことは大きな前進。本人の「戻るつもりはない」という意思は明確であり、支援はその意思を尊重した生活再建へ移行する段階にある。娘の就学継続・経済的支援・住居確保が当面の課題。関係機関（センター・児童相談所・福祉事務所・学校）との連携を密にする必要がある。
対応 本人の意思を尊重し、生活再建に向けた支援の流れ（住居・就労・経済的支援制度）を配偶者暴力相談支援センター担当者とともに説明した。娘の転校手続きについて学校教育担当窓口への連絡方法を案内した。保護命令申立ての手続きについて弁護士相談窓口を紹介した。次回面談を2週間後（10月29日）に設定した。
今後の計画 次回面談：令和5年10月29日（来所）。住居確保・生活保護申請の支援を配偶者暴力相談支援センターと連携して実施。娘の転校手続き・心理的ケアの調整。3ヶ月後（令和6年1月）に生活状況を再評価する。 【支援時期】
令和5年10月29日～
