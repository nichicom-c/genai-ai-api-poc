相談日時 令和5年10月7日（土）　19:42 ～ 20:15
相談者 相談者（本人） 対象者 藤本 さくら（34歳・女性）
相談方法 電話（着信・緊急）
目的 本人からの緊急電話着信。安全状況の確認および一時避難の意思・手段の確認。
主　訴 「夫に叩かれた。頭と腕を。娘も隣にいた。怖くて。もう限界かもしれない。どこかに逃げたい」（電話口で泣きながら）
状況（客観的） 土曜夜間の着信。電話口では本人の泣き声と、遠くで娘と思われる子どもの声が確認された。夫の声は聞こえず（別室にいる模様）。本人は「今は夫が部屋にいない間に電話した」と述べた。頭部・左腕への暴行を受けたと申告。娘（7歳）も同じ部屋にいたとのこと。自宅住所は把握済み。
状況（主観的） 「もう疲れた。ずっとこんな生活が続いていて、今日は娘の前でやられて、限界と思った。どこかに行きたいけど、お金もないし、娘をどうしたらいいか分からない。でも、このままは嫌だ」と訴えた。電話中に「もう戻ってきそう」と声のトーンが変わり、「また連絡する」と言って電話を切った。
分析・判断 身体的暴力が確認され（頭部・腕部への暴行）、子どもも目撃している。本人が「限界」「逃げたい」と初めて明確に意思を示した。緊急性が高く、本日中に配偶者暴力相談支援センターおよび警察への連絡体制を整える必要がある。子どもへの影響（面前DV）も考慮し、児童相談所との連携も視野に入れる。
対応 電話中に「今すぐ安全な場所（コンビニ・交番・隣家など）に移動できるか」を確認した。安全な場所への移動が可能であれば警察（110番）へ連絡するよう伝えた。配偶者暴力相談支援センターの夜間相談番号を伝えた。電話終了後、担当上司および配偶者暴力相談支援センターへ状況を報告し、翌日以降の連絡確認体制を整えた。
今後の計画 翌日（10/8）午前に本人への連絡確認を行う。安全が確認できた場合は一時保護・避難施設の案内を行う。配偶者暴力相談支援センター・児童相談所との連携を本日中に開始する。 【支援時期】
