相談者 相談者（本人） 対象者 西田 誠（45歳・男性）
相談方法 来所
目的 休職開始から約5週間。精神的状態の確認および心療内科治療の経過把握。休職中の生活状況・家族関係の確認。
主　訴 「休んでようやく、どれだけ追い詰められていたか分かってきた。まだ完全ではないが、少し気持ちが楽になっている。酒も量を減らせてきた」
状況（客観的） 来所時の印象は前回よりも穏やかで、表情に若干の余裕が見られた。体重は約1kg回復。心療内科には週1回通院しており、薬物療法（抗うつ薬・睡眠導入薬）と並行して認知行動療法（グループ）への参加を開始したとのこと。飲酒は「週2〜3回、ビール1〜2本程度まで減った」と述べた。睡眠は「薬の助けがあれば6時間眠れるようになった」とのこと。妻は積極的にサポートしており、子どもとの関係も少し改善してきたと述べた。
状況（主観的） 「休み始めた最初の2週間は、何もしていないことへの罪悪感がつらかった。でも、認知行動療法で『自分を責めすぎるパターン』があると指摘されて、確かにそうだなと思えてきた。先生の前回の発言（ホームのこと）も、今は遠い話のように感じる。戻りたくはないが、怖くなくなってきた」と話した。「妻に全部話したら、怒られるかと思ったら泣かれてしまって。ちゃんと話せばよかった」と述べた。
分析・判断 休職・医療介入・家族支援が重なり、状態は改善傾向にある。希死念慮に近い体験については「遠い話のように感じる」と述べており、現時点での緊急性は低下していると判断する。ただし、復職準備期に再び負荷がかかる可能性があり、段階的復職の支援と医療機関との連携継続が重要。飲酒量の減少も確認でき、自己管理力が回復しつつある。
対応 回復の経過を具体的に確認しながら肯定的なフィードバックを行った。ストレスマネジメントの基本（認知の柔軟化・休養の捉え方・相談できる関係の維持）について心療内科での取り組みと連動する形で情報提供した。復職に向けたリワークプログラムについて情報を提供した。次回面談を2ヶ月後（令和6年2月）に設定した。
今後の計画 次回面談：令和6年2月上旬（来所）。心療内科との連携を継続。復職準備の時期に応じてリワーク支援・職場調整の支援を行う。3ヶ月ごとに状態を再評価する。 【支援時期】
