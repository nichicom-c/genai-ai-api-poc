## 問題シナリオの概要

夫からの精神的・身体的・経済的暴力が「気が強い夫」という表現から始まり、身体的外傷の隠蔽、娘の前での暴言、そして緊急電話による助けを求める告白へと段階的に顕在化する。  
各記録は単独でも読めるが、5件を通して読むとDVが長期にわたって継続していたことと、被害者が被害を認識できないまま自分を責め続けていた経緯が浮かび上がる構成になっている。  
最終的には本人の意思決定による避難・配偶者暴力相談支援センターとの連携を経て生活再建の支援へと移行する。

このデータは、DV被害者支援に関する問い合わせ（例：「外傷の説明に不自然な点がある場合の対応は」「被害者が避難を決断した後の支援の流れは」）に対する**ケースベースの回答支援**テストに適している。
