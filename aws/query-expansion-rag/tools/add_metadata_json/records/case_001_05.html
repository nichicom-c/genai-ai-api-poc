相談日時 令和5年11月2日（木）　10:00 ～ 11:30
相談者 相談者（本人・夫 同席） 対象者 中村 明日香（28歳・女性）・中村 竜也（32歳・男性）／長男 中村 颯太（1歳7ヶ月）
相談方法 来所
目的 要保護対策地域協議会ケース会議（10月25日）後の支援方針の確認および父親との連携強化。支援プランの合意形成。
主　訴 母親「少し落ち着いてきた。夫がいてくれると違う。でも、一人になるとまた不安になる」。父親「妻がここまで追い詰められていたとは知らなかった。出張を減らすよう上司に相談して、承諾してもらえた」
状況（客観的） 小児科での診察の結果、子どもに揺さぶり症候群による外傷は認められず。体重はやや回復傾向（約200g増）。母親の表情は前回より穏やかになり、子どもと視線が合う場面が複数回見られた。父親は積極的に質問し、メモを取るなど協力的な態度を示した。一時保育（週3回）の利用が10月末より開始されており、本人は「少し休める」と述べている。
状況（主観的） 母親「子どもを揺さぶったことは後悔している。でも、相談できる場所があると分かって、少し楽になった。一時保育で離れる時間ができると、迎えに行くのが待ち遠しくなった」。父親「妻が一人で抱えていたことを知って、自分の責任だと思った。今後は育児に参加したい。育休の取得も検討している」。子どもは来所中、父親に向かって笑顔を見せる場面があった。
分析・判断 父親の育児参加が増え、孤立育児環境の改善が図られつつある。一時保育利用開始も母親の精神的回復に寄与していると見られる。ただし、今後の生活変化（父親の出張再開・育休未取得の場合等）により再び孤立するリスクが残る。定期的な関与と緊急時の連絡体制の維持が引き続き重要。
対応 要保護対策ケース会議での支援プランを両親にわかりやすく説明し、合意を得た。月1回の定期面談（来所または家庭訪問）を設定した。緊急時の連絡体制を確認し、保健師の直通連絡先を記載したカードを渡した。父親向けに育児支援情報（父親学級・育児休業取得の流れ）を案内した。
