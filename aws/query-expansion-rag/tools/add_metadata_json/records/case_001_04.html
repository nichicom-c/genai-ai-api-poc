相談日時 令和5年10月18日（水）　13:00 ～ 14:30
相談者 家庭訪問（通報対応） 対象者 中村 明日香（28歳・女性）／長男 中村 颯太（1歳6ヶ月）
相談方法 家庭訪問（緊急）
目的 近隣住民から「子どもの泣き声が2時間以上続いており心配」との通報を受け、緊急家庭訪問を実施。母子の安全確認および緊急支援の必要性を判断する。
主　訴 （訪問時の母親の発言）「もう限界です。どうしたらいいか分からない。死にたいとは思わないけど、このまま消えてしまいたいと思うことがある」
状況（客観的） 訪問時、室内は衣類・食器が散乱した状態。子どもは部屋の隅でぐずっており、顔色はやや悪いが意識は清明。体重が前回来所時（約1ヶ月半前）から約500g減少していると母親が申告。哺乳量が落ちているとのこと。母親は目が充血しており、衣服も乱れていた。夫は本日も出張中。近隣への挨拶もなく、訪問時に応答まで5分以上かかった。
状況（主観的） 「毎日が苦しくて。子どもが泣くたびに頭が真っ白になる」と泣きながら訴えた。しばらくして「先週、子どもが泣き止まなくて、強く揺さぶってしまった。すぐに怖くなって止めたけど…それ以来、子どもが私を見て怯えている気がする」と告白した。声を詰まらせながら「私は最低な母親だと思う」と繰り返した。告白後は「言わなければよかったかな」とも漏らし、支援への恐れと罪悪感の間で揺れていた。
分析・判断 「強く揺さぶった」との自己申告は揺さぶり症候群（SBS）のリスクを示唆する重大な情報。子どもの体重減少・表情の乏しさとも整合する。母親自身も「消えたい」と述べており精神的危機状態にある。本日中に要保護児童対策地域協議会への情報提供が必要。子どもの緊急医療受診を手配する。
対応 母親の気持ちを受け止め、「話してくれてありがとう。子どもを一緒に守るために専門のチームと相談させてほしい」と丁寧に伝えた。要保護対策地域協議会への情報提供を行う旨を説明し、本人の了承を得た。子どもについて緊急小児科受診（市民病院）を手配した。夫への連絡を促し、翌日（10/19）の来所面談を設定した。
今後の計画 翌日（10/19）に父親同席での面談を実施。要保護対策地域協議会にてケース会議を開催（10/25予定）。医療機関での子どもの経過確認を継続する。 【支援時期】
