別記様式１　（第3回）
相談日時 令和5年9月5日（火）　10:00 ～ 11:00
相談者 相談者（本人） 対象者 中村 明日香（28歳・女性）／長男 中村 颯太（1歳5ヶ月）
相談方法 来所
目的 前回電話相談（7月24日）のフォローアップ。子どもの健康状態の確認および一時保育利用状況の把握。
主　訴 「ちょっとした打撲があって、念のため見てもらおうと思って。それと、最近子どもが全然笑わなくて、私のことが嫌いなのかと思ってしまう」
状況（客観的） 来所時、子どもの右前腕部に直径約3cmの内出血が確認された。母親は「2日前にベビーカーのベルトから抜け出して床に落ちた」と説明。打撲の位置・形状について転落との因果関係を断定することはできない。一時保育の申込書は「途中まで書いたが出せていない」とのこと。子どもは来所中ぐずりが多く、表情がやや乏しかった。
状況（主観的） 打撲の状況について詳しく尋ねると、母親の表情が一瞬硬くなったが、すぐに「本当に落ちたんです。見ていたんです」と繰り返した。子どもに声をかけると、子どもは母親よりも保健師の方へ顔を向ける場面が複数回見られた。母親は「子どもに嫌われているみたい。育て方が悪かったのかな」と自分を責める発言をした。疲労感は前回より増している印象。
分析・判断 打撲の原因説明に明確な矛盾は断言できないが、前回の「叩きたくなる」という発言・今回の打撲・子どもの表情の乏しさが重なり、複合的なリスク要因として慎重に見る必要がある。単独では判断が難しいが、継続観察を強化し、必要に応じて要保護対策協議への移行を視野に入れる段階と判断する。担当上司への報告を行う。
対応 打撲については「詳しく教えてもらえますか」と穏やかに確認し、強制的な印象を与えないよう配慮しながら詳細を記録した。子どもの健康状態について小児科受診を勧め、受診先の情報を提供した。次回の来所日を2週間後（9月19日）に設定し、継続的な支援を約束した。面談後、担当上司に状況を報告した。
今後の計画 9月19日（火）に来所面談を実施（小児科受診結果の確認含む）。内部でのケース共有を継続。要保護対策協議への移行判断を上司と協議する。 【支援時期】
