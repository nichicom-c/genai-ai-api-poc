相談日時 令和5年10月30日（月）　14:00 ～ 15:20
相談者 相談者（本人） 対象者 西田 誠（45歳・男性）
相談方法 来所
目的 前回（9月4日）来所のフォローアップ。職場から休職を勧められたとのことで来所。今後の方針についての支援。
主　訴 「先週、上司と産業医から休職を勧められた。正直、ほっとした気持ちもあるけど、このまま自分が終わってしまうような気もして怖い」
状況（客観的） 10月中旬、産業医との面談（初めて実施）で休職を勧められた。同時期に心療内科を初受診し、「適応障害・抑うつ状態」と診断を受けたとのこと。現在は診断書を職場に提出し、11月から休職に入る予定。来所時の顔色は悪く、体重はさらに減少（初回比−5kg）。飲酒については「先生に止めるよう言われた。今は量を減らしている」と述べた。妻が同行を申し出たが本人が断ったとのこと。
状況（主観的） 「休職と聞いて最初は情けなくなった。でも、もう限界だった。最近は通勤電車の中でホームに立っているとき、ふと『このまま飛び込んだらどうなるんだろう』と思ったことがあった。すぐに打ち消したが、そういう考えが浮かんだこと自体が怖かった」と小声で打ち明けた。その後「死にたいわけじゃない。ただ、消えてしまいたい気持ちが一瞬あった」と付け加えた。表情は沈んでおり、涙をこらえる場面があった。
分析・判断 「ホームで飛び込みを考えた」という発言は希死念慮に準じる重大なサインとして記録する。本人は「すぐに打ち消した」「死にたいわけではない」と述べているが、今後の状態変化に細心の注意が必要。受診・休職につながったことは前進だが、休職開始直後は不安定になりやすい時期でもあるため、医療機関・家族との連携を密にする。
対応 「話してくれてありがとう」と伝え、希死念慮に近い体験について「今もそういった気持ちはあるか」を慎重に確認した（「今はない」との返答）。緊急時の連絡先（相談窓口・医療機関・保健師直通番号）を記載したカードを手渡した。休職中の過ごし方（過度に自責しないこと、規則正しい生活）について簡単に説明した。妻への状況共有の同意を得た上で、妻への情報提供と協力依頼の方針を確認した。
今後の計画 休職開始後5週間目（12月初旬）を目安に来所面談を設定。心療内科の通院状況・状態変化を継続把握。妻へのフォローアップも検討する。 【支援時期】
令和5年12月初旬
