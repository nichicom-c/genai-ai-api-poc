相談日時 令和5年5月15日（月）　12:10 ～ 12:50
相談者 相談者（本人） 対象者 西田 誠（45歳・男性）
相談方法 来所
目的 肩こり・慢性的な疲労感を訴えて来所。職場の定期健康診断後に「一度相談に来るように」と産業医より案内を受けた。生活習慣および職場ストレスの把握。
主　訴 「肩と首がずっと凝っていて、最近は目の奥が痛い。仕事が4月から変わって忙しくなった。まあ慣れれば大丈夫だと思うんですが」
状況（客観的） 来所時の印象は落ち着いており、笑顔で話す場面も多い。定期健診の結果では血圧がやや高め（138/88）、BMIは標準範囲内。4月に部署異動があり、現在は中間管理職として部下6名のマネジメントを担っているとのこと。残業は月40〜50時間程度と述べた。妻（43歳）・長男（高校2年）・長女（中学1年）の4人家族。飲酒習慣あり（「週3〜4回、ビール1〜2本程度」）。
状況（主観的） 「異動したばかりで仕事のやり方が全然違って、正直まだついていけていない部分がある。でも、弱音を吐ける立場じゃないから」と笑いながら述べた。「家に帰ってもすぐ眠れなくて、スマホをついつい見てしまう。妻には『最近元気ない』と言われるんですが、自分では気づかないですね」と話した。睡眠時間は平均5〜6時間と述べた。全体として問題を軽視し、明るく振る舞う傾向が見られた。
分析・判断 現時点では深刻な状態ではないと見られるが、新たな役職・業務量の増加・睡眠の質の低下が重なっており、ストレス蓄積のリスクがある。本人は問題を軽視し「慣れれば大丈夫」と述べているが、妻からの指摘もあり、客観的な経過観察が必要。血圧についても継続確認が望ましい。
対応 ストレスの仕組みと身体症状への影響について簡単に説明した。睡眠の質を高めるための具体的な工夫（入浴・就寝前のスクリーン制限・カフェイン摂取時間帯）を案内した。飲酒習慣については現在の量を記録しておくよう伝えた。「気になることがあればいつでも相談を」と伝え、2ヶ月後を目安に次回を案内した。
今後の計画 7月上旬を目安に次回面談を設定。睡眠・飲酒・残業時間の変化を確認する。血圧の推移についても把握する。 【支援時期】
