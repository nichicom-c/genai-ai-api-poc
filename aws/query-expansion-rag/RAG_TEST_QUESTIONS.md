# RAG機能テスト用 質問集

データ構成：3ケース（育児虐待リスク・DV・職場メンタル）× 各5回の相談記録（計15件）

---

## 1. 単一ドキュメント参照

特定のケースに答えが含まれているため、正確な検索・引用ができているかを確認します。

| 質問 | 期待されるケース |
|---|---|
| 揺さぶりを告白した母親のケースで、保健師はどのような対応をとりましたか？ | case_001_04 |
| 右頬の内出血があり「棚にぶつけた」と説明した相談者への保健師の対応は？ | case_002_02 |
| 「ホームで飛び込みを考えた」と告白した相談者について、保健師はどう判断しましたか？ | case_003_04 |

---

## 2. 複数文書横断クエリ（時系列理解）

5件が時系列でつながっているため、文書をまたいだ文脈理解が試せます。

```
case_001の対象者は最初の相談からどのように状況が変化しましたか？
```
```
藤本さくらさんは避難を決断するまでにどのような経緯がありましたか？
```
```
西田誠さんの飲酒習慣は相談を重ねるなかでどう変化しましたか？
```

---

## 3. クエリルーティング（ケース識別）

3ケースが混在するため、クエリが正しいケースの文書を引いてくるかを確認します。

```
育児中に「叩きたくなる」と打ち明けた相談者への対応事例はありますか？
```
→ case_001を引くべきで、case_002やcase_003を混ぜないか確認

```
夫からの暴力で家を飛び出した相談者を支援した記録はありますか？
```
→ case_002のみ引くべき

---

## 4. 対応方針支援モード向け質問

チャット画面の「対応方針支援」モード、または相談記録画面の「対応方針支援」ボタンで使用します。
現在の相談内容として入力し、過去事例をもとに方針を提案できるかを評価します。

```
30代女性、夫から怒鳴られると相談してきた。
外傷はないが顔色が悪く、話すことを躊躇している様子。
```
→ case_002の初期〜中期の対応が参照されるか確認

```
40代男性、仕事が忙しく眠れないと来所。
「酒を飲まないと寝られない」と言っている。家族関係も少し悪化気味。
```
→ case_003の第2〜3回が参照されるか確認

```
20代女性、1歳の子どもを育てている。夫は出張が多く孤立している様子。
「最近イライラすることが増えた」と打ち明けてきた。
```
→ case_001の初期対応が参照されるか確認

---

## 5. ネガティブテスト（ハルシネーション確認）

知識ベース外の情報を聞いてみることで、RAGが存在しない情報を作り上げないかを確認します。

```
高齢者介護でアルツハイマーが進行した場合の施設入所手続きを教えてください。
```
→ 該当する記録がないため「わかりません」と答えるべき

---

## 推奨テスト順序

1. **3（ルーティング確認）** — 正しいケースの文書を引けているか
2. **1（精度確認）** — 具体的な記録内容を正確に参照できているか
3. **2（横断理解）** — 複数文書の時系列をまとめられるか
4. **4（対応方針支援）** — 過去事例をもとに実用的な提案ができるか
5. **5（ネガティブ）** — 知識ベース外でハルシネーションが起きないか
