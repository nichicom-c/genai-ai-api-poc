# AWS 運用コスト見積もり — Query Expansion RAG

**リージョン**: ap-northeast-1（東京）  
**デプロイ構成**: dev 環境 × 1 アプリ  
**最終更新**: 2026-05-25

---

## リクエスト処理フロー（コスト構造）

1リクエストあたり **7〜8回の LLM 呼び出し**が発生します（`n_queries=3` デフォルト時）。

| ステップ | 呼び出し数 | モデル（`qerag.toml` 設定値） | 推定トークン（入力/出力） |
|---------|-----------|----------------------------|------------------------|
| ① クエリ拡張 | ×1 | `jp.amazon.nova-2-lite-v1:0` | ~650 / ~150 |
| ② RetrieveAndGenerate | ×3（並列） | `jp.amazon.nova-2-lite-v1:0`（KB経由） | ~8,100 / ~200 × 3 |
| ③ 関連度評価 | ×3（並列） | `jp.amazon.nova-2-lite-v1:0` | ~6,450 / ~700 × 3 |
| ④ 回答生成（通常モード） | ×1 | `jp.anthropic.claude-haiku-4-5-20251001-v1:0` | ~4,550 / ~400 |
| ④' 回答生成（詳細モード） | ×1 | `jp.amazon.nova-2-lite-v1:0`（qerag.toml で上書き） | ~4,550 / ~800 |

> ⚠️ `answer_generation.modelId` は `qerag.toml` で**上書きされていない**ため、デフォルトの Claude Haiku 4.5 が使用されます。これがコストの主要因です。

## コスト最適化の提案

| 対策 | 節減効果 | 方法 |
|-----|---------|-----|
| **① `answer_generation` を Nova Lite に変更** | **Bedrock 費用 約 60% 削減** | `qerag.toml` の `[answer_generation]` に `modelId = "jp.amazon.nova-2-lite-v1:0"` を追加 |
| ② `retrieve_and_generate` → `retrieve` に変更 | 約 19% 削減 | Lambda コードで KB Retrieve API を使用 |
| ③ `n_queries` を 3→2 に削減 | ②③ステップ 33% 削減 | API リクエストの `n_queries` パラメータを変更 |
| ④ `KB_NUM_RESULTS` を 20→10 に削減 | 関連度評価トークン数 50% 削減 | Lambda 環境変数変更 |

①の対策だけで月 **$94〜$152 の削減**が見込めます（500〜1,000 req/日 の場合）。

## ベクターストア別コスト比較：S3 Vectors vs OpenSearch Serverless

### OpenSearch Serverless（AOSS）の料金構造

AOSS は **OCU（OpenSearch Compute Unit）** 単位で課金され、コレクションが存在する限り**リクエストゼロでも常時課金**されます。

| OCU タイプ | 用途 | 最小 OCU数 |
|-----------|-----|----------:|
| Indexing OCU | ドキュメント取り込み・更新 | 1 OCU |
| Search OCU | ベクトル検索・クエリ | 1 OCU |
| **合計（standbyReplicas=DISABLED）** | | **2 OCU** |
| **合計（standbyReplicas=ENABLED）** | HA 構成 | **4 OCU** |

OCU 単価: **$0.24 / OCU-時間**（ap-northeast-1）

### AOSS 月額固定費

| 構成 | OCU 数 | **月額（24 時間 × 30 日）** |
|-----|------:|------------------------:|
| standbyReplicas=DISABLED（dev/test） | 2 OCU | **$345.60 / 月** |
| standbyReplicas=ENABLED（prd 推奨） | 4 OCU | **$691.20 / 月** |

> コード上 `standbyReplicas` は `ragKnowledgeBaseStandbyReplicas` コンテキスト値で切り替え可能。未指定時は DISABLED。

### ベクターストア別 総コスト比較

Bedrock FM 推論・Lambda・API Gateway・WAF・KMS は両構成で同一のため、ベクターストア部分の差異のみ示します。

#### 維持費のみ（リクエストほぼゼロ）

| 項目 | S3 Vectors | AOSS (standby=OFF) | AOSS (standby=ON) |
|-----|----------:|-----------------:|----------------:|
| ベクターストア | <$0.01 | $345.60 | $691.20 |
| WAF + KMS | $8.00 | $8.00 | $8.00 |
| **合計** | **~$8 / 月** | **~$354 / 月** | **~$700 / 月** |

#### 利用規模別 月額合計（ベクターストア + 全サービス込み）

| 利用規模 | S3 Vectors | AOSS (standby=OFF) | AOSS (standby=ON) |
|---------|----------:|-----------------:|----------------:|
| 維持費のみ（~0 req） | **~$8** | **~$354** | **~$700** |
| 軽量（100 req/日） | **~$34** | **~$380** | **~$725** |
| 中程度（500 req/日） | **~$138** | **~$484** | **~$830** |
| フル利用（1,000 req/日） | **~$269** | **~$615** | **~$961** |

### S3 Vectors vs AOSS の選択指針

| 観点 | S3 Vectors | OpenSearch Serverless |
|-----|-----------|----------------------|
| **維持費** | ほぼゼロ（従量） | 最低 $346/月（常時課金） |
| **デモ・低頻度用途** | 最適 | コスト過大 |
| **高トラフィック** | 問題なし | スケール時に有利な場合あり |
| **日本語全文検索** | 非対応 | kuromoji アナライザあり |
| **フィルタリング** | メタデータ（1KB 制限） | 豊富なクエリ構文 |
| **マネージド度** | 高（設定シンプル） | 中（インデックス管理が必要） |
| **現在の実装** | `qeRagAppNamesWithS3Vectors` | `qeRagAppNames` / `qeRagAppNamesWithSharedCmek` |

**結論**: デモ・低頻度利用では **S3 Vectors が圧倒的にコスト有利**（差額 $346〜$692/月）。本番で高度な検索機能や HA が必要になった場合に AOSS への移行を検討する。
